---
title: Request logs
description: Filter and inspect operational request metadata.
---

The request log displays date, application, provider, model, endpoint, modality, status, per-request tokens, accumulated tokens, and duration.

It refreshes every five seconds by default. Use **Disable auto-refresh** to pause updates and **Enable auto-refresh** to resume. Polling stops when you leave the page.

The text filter matches displayed metadata and remains active during refreshes. Authentication failures are recorded without storing the supplied credential.

Request and response bodies do not appear in this log or in SQLite. See [privacy and storage](../reference/privacy-and-storage/) for optional conversation logging.
